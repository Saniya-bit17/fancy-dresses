# Maison Solène — React Frontend

Haute-couture evening and occasion wear web application, converted from the single-file Claude design into a modular React app with dedicated page directories, reusable components, and elevated typography.

## Quick Start

### 1. Install Dependencies
```powershell
npm.cmd install
```

### 2. Run Development Server
```powershell
npm.cmd run dev
```
Open **[http://localhost:3000/](http://localhost:3000/)** in your browser.

### 3. Build for Production
```powershell
npm.cmd run build
```

## Pages Architecture
- `src/pages/HomePage/` — Landing page with hero sketch, marquee strip, lookbook grid, atelier story, process, testimonials, and newsletter.
- `src/pages/CollectionPage/` — Full catalog with category filters, search, sort, and quick inspect cards.
- `src/pages/ProductDetailPage/` — Dedicated gown page with interactive 9-shade selector and custom measurements.
- `src/pages/AtelierPage/` — Jaipur Courtyard No. 4 history, craft pillars, and workshop blueprint.
- `src/pages/FittingPage/` — 3-step bespoke fitting methodology, 12 anatomical points, and FAQs.
- `src/pages/AppointmentsPage/` — Salon and virtual consultation booking experience.
- `src/pages/ContactPage/` — Showroom addresses, visiting hours, and bespoke inquiry form.
